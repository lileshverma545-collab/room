# Room Duel

Online Tic-Tac-Toe with room codes. Firebase Realtime Database + Capacitor (Android).

```
room-duel/
├── www/
│   └── index.html            ← the whole game (UI + logic + admin)
├── .github/workflows/
│   └── build-apk.yml         ← builds the APK on every push to main
├── database.rules.json       ← paste into Firebase → Realtime Database → Rules
├── capacitor.config.json
├── package.json
├── .gitignore
└── README.md
```
(`android/` appears after you run `npx cap add android`.)

See the chat message for the full setup steps.
